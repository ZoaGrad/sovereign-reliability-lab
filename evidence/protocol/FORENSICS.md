
# Sovereign Forensic Protocol: V1.1

## 1. Overview
This document defines the canonical validation rules for "Sovereign Fingerprints" generated by the SpiralOS Phase Controller. Any evidence artifact claiming to prove deterministic fleet synchronization must satisfy this protocol.

## 2. The Integrity Chain
1. **Canonicalization**: The JSON payload must be stringified with keys sorted alphabetically and zero optional whitespace.
2. **Signature**: The resulting string is hashed using the FNV-1a 32-bit algorithm.
3. **Verification**: The `metadata.integrity_hash` must exactly match the recomputed signature of the `config`, `summary`, and `samples` blocks.

## 3. Metric Re-Derivation (Cold Audit)
Metrics provided in the `summary` block are considered "claimed" until verified. The verifier MUST:
- Re-calculate **SPI** (Spread-of-Arrivals Index) for every tick in `samples`.
- Enforce **K-Factor Gating**: A "Max Sustainable Entropy" claim is only valid if the fleet maintained SPI >= 0.85 for at least 3 consecutive complete ticks at that entropy level.

## 4. Verdict Classification
- **VALIDATED (0)**: Integrity match + sufficient stable samples.
- **TAMPERED (2)**: Integrity hash mismatch.
- **INVALID_SCHEMA (3)**: Missing required fields or corrupted structure.
- **EVIDENCE_DEFICIT (4)**: Artifact lacks the required consecutive stable samples (K < 3) to support its summary claims.
